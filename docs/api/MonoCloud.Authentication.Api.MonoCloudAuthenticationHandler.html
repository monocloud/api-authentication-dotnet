Remarks

This handler extends JwtBearerHandler. JWT access tokens are validated by the base handler (signing keys, issuer, audience, lifetime) while opaque access tokens are validated through RFC 7662 introspection by this handler. Certificate binding (RFC 8705) and group claim normalization are applied on both paths.

Because IOptionsMonitor<TOptions> is covariant, the base handler's Options holds the MonoCloudAuthenticationOptions instance produced by this scheme's options pipeline.
