Defines an abstract interface for caching access token introspection results. This interface is intended to be used to temporarily store and retrieve the claims resolved from token introspection.

public interface IIntrospectionCache

Remarks

Only tokens validated via introspection are cached — opaque tokens, and JWTs when IntrospectJwtTokens is true. Locally validated JWTs are never cached. Implementations must be registered in the service collection with a singleton lifetime.
