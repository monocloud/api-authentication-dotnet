Remarks

This type derives from JwtBearerOptions, so all of the standard JWT bearer options (Authority, TokenValidationParameters, Audience, SaveToken, MapInboundClaims, IncludeErrorDetails, ...) apply here as well and behave exactly as they do for AddJwtBearer. Set Authority to the tenant domain; a value without a scheme is prefixed with https:// during post-configuration. The members declared below are the MonoCloud specific additions.
