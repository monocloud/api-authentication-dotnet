Remarks

This type derives from JwtBearerEvents, so the standard bearer events (OnMessageReceived, OnTokenValidated, OnAuthenticationFailed, OnChallenge and OnForbidden) are available here and are raised for both JWT and opaque (introspected) tokens. The events declared below are the MonoCloud specific additions.
